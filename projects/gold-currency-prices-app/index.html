Gold & Currency Prices App

تطبيق اسعار الذهب و العملات

Live gold and currency rates

year
2020
type
Individual

A React Native mobile app that displays live gold and currency exchange rates. It pulls real-time pricing data from a REST API and presents it through a smooth, animated interface with persistent local storage.

تطبيق جوال مبني بتقنية React Native يعرض أسعار الذهب والعملات بشكل لحظي. يجلب التطبيق بيانات التسعير الحية من واجهة REST API ويعرضها عبر واجهة سلسة ومتحركة مع تخزين محلي دائم للبيانات.
