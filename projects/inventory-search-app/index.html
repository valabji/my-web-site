Inventory Search App

تطبيق للبحث في المخزون

Mobile inventory lookup with admin panel

year
2020
type
Individual
built in
3 hours
data
PHP REST API

A React Native mobile app for searching and looking up inventory items, paired with a companion admin dashboard for managing them. It retrieves stock data from a PHP REST API, giving users fast access to inventory records on the go.

تطبيق جوال مبني بتقنية React Native للبحث في المخزون والاطلاع على عناصره، مع لوحة تحكم مرافقة لإدارته. يجلب التطبيق بيانات المخزون من واجهة برمجية PHP REST API، مما يتيح الوصول السريع إلى سجلات المخزون.
