Zikr — Islamic Remembrance App

تطبيق ذِكْر — البداية

The 2021 foundation for daily Islamic remembrances

type
Individual
data
JSON

The original Zikr mobile app offered a curated collection of Islamic remembrances (adhkar) and supplications for daily use. Built with React Native, it featured smooth animated transitions and offline access to its content.

النسخة الأولى من تطبيق «ذِكْر» قدّمت مجموعة مختارة من الأذكار والأدعية الإسلامية للاستخدام اليومي. طُوّرت باستخدام React Native، وركّزت على الانتقالات السلسة وإتاحة المحتوى دون اتصال بالإنترنت.

Highlights

  • Curated daily azkar and supplications
  • Interactive digital tasbih counter
  • Favorites, Arabic and English, and offline reading

Tech Stack

  • Reanimated
  • React Native Elements
  • Redux
  • AsyncStorage
  • React Navigation

2026 — five years later

Zikr

Five years later, Zikr has grown into a broader daily companion: prayer times and athan notifications, qibla direction, an integrated Quran reader, a multi-tasbih counter, Islamic library tools, and a more customizable experience.

Highlights

  • Prayer times, athan notifications, next-prayer countdown, and prayer log
  • Qibla compass, Hijri calendar, and home-screen widget
  • Integrated Quran reader with recitations, tafsir, translation, and offline listening
  • Multiple tasbih counters with statistics, plus radio, daily wird, hadith, and share cards
  • Modern themes, menu personalization, Arabic, and English

Tech Stack

  • React Native
  • Expo
  • React Navigation
  • Redux Toolkit
  • AsyncStorage
  • Expo Audio
  • Jest
