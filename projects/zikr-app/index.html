Zikr — Islamic Remembrance App

تطبيق ذِكْر

Daily Islamic remembrances on mobile

type
Individual
data
JSON

Zikr is a mobile app that offers a curated collection of Islamic remembrances (adhkar) and supplications for daily use. Built with React Native, it features smooth animated transitions and offline access to its content.

تطبيق ذِكْر هو تطبيق للهواتف المحمولة يقدّم مجموعة منسّقة من الأذكار والأدعية الإسلامية للاستخدام اليومي. مبني باستخدام React Native، ويتميّز بانتقالات حركية سلسة وإتاحة المحتوى دون اتصال بالإنترنت.

Tech Stack

  • React Native
  • Reanimated
  • React Native Elements
  • Redux
  • AsyncStorage
  • React Navigation
