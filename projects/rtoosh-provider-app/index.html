Rtoosh Service Provider App

تطبيق رتوش لمقدمي الخدمة

On-demand services for providers

year
2020
type
Team · Employment
built in
6 months
data
REST API

Rtoosh is a React Native mobile app for service providers, enabling them to manage on-demand bookings and reach customers through location-aware features. It integrates live geolocation and mapping, push notifications, and in-app payments to streamline the provider's workflow.

رتوش هو تطبيق جوال مبني بتقنية React Native موجّه لمقدمي الخدمة، يتيح لهم إدارة الحجوزات عند الطلب والوصول إلى العملاء عبر ميزات تعتمد على تحديد الموقع. يدمج التطبيق خدمات تحديد المواقع والخرائط الحية والإشعارات والدفع داخل التطبيق لتسهيل سير عمل مقدّم الخدمة.
