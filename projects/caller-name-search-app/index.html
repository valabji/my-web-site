Caller Name Lookup App

تطبيق البحث عن اسم المتصل

Identify unknown callers instantly

year
2020
type
Individual
built in
5 days
data
PHP REST API

A React Native mobile app that identifies the name behind an incoming or unknown phone number. It looks up caller identities through a PHP REST API and enriches results using the device's call log, contacts, and SIM data.

تطبيق جوال طُوّر باستخدام React Native للتعرّف على أصحاب الأرقام الواردة أو المجهولة. يبحث عن هوية المتصل عبر واجهة REST API مطوّرة بلغة PHP، ويستكمل معلومات النتائج بالاستعانة بسجل المكالمات وجهات الاتصال وبيانات شريحة SIM على الجهاز.
