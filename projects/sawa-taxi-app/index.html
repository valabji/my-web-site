Sawa Taxi App

Ride-hailing platform for Sudan

Sawa Taxi is a ride-hailing platform built for Sawa Taxi in Sudan, comprising two native Android apps — one for riders and one for drivers — backed by a web admin dashboard for operations management. It handles live trip booking, driver-rider matching, and route and fare calculation using Google Maps and Distance Matrix, with local SMS-based verification.

سوا تاكسي منصة لطلب سيارات الأجرة طُورت لشركة سوا تاكسي في السودان، وتتكوّن من تطبيقَي أندرويد أصليين، أحدهما للزبون والآخر للسائق، إضافةً إلى لوحة تحكم ويب لإدارة العمليات. يتيح النظام حجز الرحلات مباشرةً والمطابقة بين السائق والزبون وحساب المسارات والأجرة عبر خرائط جوجل ومصفوفة المسافات، مع التحقق عبر رسائل SMS محلية.
