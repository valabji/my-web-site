Rtoosh App

تطبيق رتوش

Location-based mobile app with integrated payments

year
2020
type
Team · Employment
built in
6 months
data
REST API

Rtoosh is a cross-platform mobile application built with React Native, featuring location-aware services powered by Google Maps and Apple Maps with geolocation and geocoding. The app integrates PayTabs for in-app payments and OneSignal for push notifications, with state handled through Redux and smooth interactions driven by Reanimated.

رتوش تطبيق جوال متعدد المنصات مبني باستخدام React Native، يقدم خدمات معتمدة على الموقع الجغرافي عبر خرائط Google وApple مع تحديد المواقع والترميز الجغرافي. يدمج التطبيق بوابة PayTabs للدفع داخل التطبيق وOneSignal للإشعارات الفورية، مع إدارة الحالة عبر Redux وتفاعلات سلسة باستخدام Reanimated.
