النسخة الأولى من تطبيق «ذِكْر» قدّمت مجموعة مختارة من الأذكار والأدعية الإسلامية للاستخدام اليومي. طُوّرت باستخدام React Native، وركّزت على الانتقالات السلسة وإتاحة المحتوى دون اتصال بالإنترنت.

أبرز المزايا

  • مجموعة مختارة من الأذكار والأدعية اليومية
  • مسبحة رقمية تفاعلية
  • المفضلة والعربية والإنجليزية والقراءة دون إنترنت

التقنيات المستخدمة

  • React Native
  • Reanimated
  • React Native Elements
  • Redux
  • AsyncStorage
  • React Navigation

٢٠٢٦ — بعد خمس سنوات

ذِكْر

بعد خمس سنوات، تطوّر «ذِكْر» إلى رفيق يومي أشمل: مواقيت الصلاة وإشعارات الأذان، واتجاه القبلة، وقارئ قرآن متكامل، ومسابح متعددة، وأدوات للمكتبة الإسلامية، وتجربة أكثر قابلية للتخصيص.

أبرز المزايا

  • مواقيت الصلاة وإشعارات الأذان وعدّاد للصلاة القادمة وسجل للصلوات
  • بوصلة للقبلة وتقويم هجري وودجت للشاشة الرئيسية
  • قارئ قرآن متكامل مع تلاوات وتفسير وترجمة وتحميل للاستماع دون إنترنت
  • مسابح متعددة مع إحصاءات، وإذاعة وورد يومي وحديث اليوم وبطاقات مشاركة
  • ثيمات حديثة وتخصيص للقائمة ودعم العربية والإنجليزية

التقنيات المستخدمة

  • React Native
  • Expo
  • React Navigation
  • Redux Toolkit
  • AsyncStorage
  • Expo Audio
  • Jest
